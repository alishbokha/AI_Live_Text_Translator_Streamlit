# 🌍 AI Live Text Translator

A multilingual AI text translation application built with **NLLB-200**, Hugging Face Transformers, PyTorch, and Streamlit.

## Features

- English, German, French, Spanish, Italian and Hindi
- Automatic language detection
- Neural machine translation using NLLB-200
- Manual source and target language selection
- Swap languages
- Clear input/output
- Streamlit web interface

## Model

`facebook/nllb-200-distilled-600M`

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deployment

This project can be deployed using Streamlit Community Cloud from a GitHub repository.
